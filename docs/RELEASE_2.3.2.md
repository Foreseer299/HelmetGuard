# HelmetGuard 2.3.2 — 小雅离线女声

用户已确认通知测试有播报，本次按反馈调整监听提示，并替换不满意的语音。

- 未连接文案改为“通知监听：等待系统连接（需要关闭通知使用权再重新打开）”，保留2.3.1自动请求重连和手动重连入口。
- 移除旧AISHELL-3模型，换成Piper小雅普通话单女声的sherpa-onnx INT8转换包；ONNX本体18,652,795字节，连同中文词典和FST约21MB，比旧约32MB资源小。
- 默认自动选择优先内置小雅；音色菜单可明确选择“小雅 · 自然女声（内置离线）”或合格系统离线中文音色。已有明确系统音色选择仍保留，想换新声可在菜单选择小雅。
- 内置小雅使用自然音高，只调语速；音高滑块仅用于系统音色，避免无效设置。试听和短信/来电播报使用相同音色路径。
- 离线合成无需等待系统TTS初始化，仍经16kHz单声道PCM供手机测试与头盔音频协议使用。无云端请求，不增加INTERNET权限。
- 下载脚本校验模型包、各资源和AAR哈希，移除旧资源防止重复打包；保留原始模型卡。模型卡标注非商业用途，符合本项目已说明的非营利课程原型用途，不宣称商业授权。详情见THIRD_PARTY_TTS.md。

版本52/2.3.2，com.helmet.guard.debug，签名与已交付2.2alpha04/2.3系列一致，可覆盖。默认关闭的手机测试播报不自动打开；其他通知隐私、来源、事故优先级与参考固件不变。

测试记录见TEST_RESULTS_2.3.2.md。音色自然度属个人听感，交付包附应用实际生成试听音频；可在手机音色菜单试听后选择。未把信号/播放测试当成真人听评。
